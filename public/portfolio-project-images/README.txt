Portfolio project images — curated from your uploaded screenshots

1. Copy the included project folders into your portfolio app's `public/projects/` directory.
   Final structure should be: `public/projects/<project-slug>/...`
2. Open `IMAGE_FIELD_MAPPING.js` and copy the `coverImage`, `heroImage`, and `gallery`
   values into the matching objects in your existing `projects.js`.
3. Keep the project slugs exactly as shown in the folder names.

Selection notes:
- Cover images were chosen to show a strong representative screen in a project card.
- Hero images were chosen to introduce the project or show its key experience.
- Gallery images show distinct features where available.
- These are visual selections based on the screenshots provided.
